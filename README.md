# FizzBuzz (1 〜 50)

1 から 50 までの FizzBuzz の判定結果をブラウザ上で視覚的に分かりやすく表示する Web アプリケーションです。

## 概要

数値 1 〜 50 をグリッドカード形式で並べ、判定結果に応じて色分けして表示します。
外部ライブラリに依存せず、HTML / CSS / JavaScript の単一ファイルで完結しています。

## ルール

| 条件 | 表示 | バッジ色 |
| :--- | :--- | :--- |
| **15 の倍数** (3 と 5 の公倍数) | `FizzBuzz` | パープル |
| **3 の倍数** | `Fizz` | ブルー |
| **5 の倍数** | `Buzz` | オレンジ |
| **上記以外** | 数値そのまま | グレー |

## 特徴

- **カード形式のグリッドレイアウト**: CSS Grid によるレスポンシブデザイン（PC・スマートフォン対応）
- **直感的なカラーリング**: タイプごとに視覚的に識別しやすい配色
- **ホバーエフェクト**: カードにカーソルを合わせると浮き上がるアニメーション
- **ゼロ依存**: ビルドやローカルサーバー不要で、ファイルをブラウザで直接開くだけで動作

## 使い方

1. 本リポジトリをクローンまたはダウンロードします。
2. `index.html` をお使いの Web ブラウザ（Chrome、Edge、Safari、Firefox など）で開きます。

```bash
# クローン例
git clone git@github.com:j4091qhi-blip/-1118-fizzbuzz.git
cd -1118-fizzbuzz

# Windows でブラウザ起動の例
start index.html
```
